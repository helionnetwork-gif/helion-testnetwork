# Helion — Roadmap v0.1

## Vaihe 0 — Testnet foundation (nyt)
- Custodial wallet, auth
- Miner, staking, swap
- Leaderboard + guide
- tBNB deposit / withdraw (ulos omalle lompakolle)
- React app (`helion-app`) + legacy HTML

## Vaihe 1 — Testnet complete
- Spot HEL/BNB (deposit → order book → withdraw)
- Yhtenäinen UI (helion-app ensisijainen)
- Hybrid mining emission näkyviin + kontraktipäivitys kun valmis
- Tester-ohjelma / pisteet

## Vaihe 2 — Product polish
- PWA (asenna kotiin)
- Vakaampi API-host (vähemmän cold start)
- Rate limits, backup, status-sivu

## Vaihe 3 — Mainnet prep
- Tokenomics v1.0 lukitus
- Auditit
- Likviditeetti- ja treasury-suunnitelma (multisig)
- Dokumentaatio + riskit

## Vaihe 4 — Mainnet launch
- HEL mainnet, kiinteä 100 mrd supply
- Miner / staking / swap parametrein
- Spot kun likviditeetti riittää
- Community-jako sääntöjen mukaan

## Vaihe 5 — Kasvu
- Capacitor / store (valinnainen)
- Lisäparit, governance
- Partnerit

## Emission & fees (muistio)
- Mining: hybrid (90 pv halving, min 0.5, community 18 % katto)
- Fees: tBNB; viikkopalkkiot rankingilla (suunnitelma)
