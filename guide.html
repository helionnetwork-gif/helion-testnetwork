Helion on BSC Testnet -projekti (Chain ID 97). Kaikki tokenit ovat testiarvoa — ei oikeaa rahaa. Helion luo sinulle custodial-lompakon (palvelin allekirjoittaa ketjutapahtumat). Ketjutoiminnot (miner, stake, swap) tarvitsevat pienen määrän tBNB:tä gas-maksuihin kyseisessä lompakossa.

1. Luo tili ja kirjaudu

  1. Avaa kirjautumissivu.
  2. Valitse Rekisteröidy, anna käyttäjänimi ja salasana.
  3. Rekisteröityessä Helion luo sinulle automaattisesti BSC-lompakon (custodial).
  4. Kirjautumisen jälkeen pääset Wallet-, Miner-, Staking-, Swap- ja Spot-sivuille.

Voit myöhemmin linkittää MetaMask-osoitteen Wallet-sivulla (valinnainen kirjautuminen allekirjoituksella).

2. Helion-lompakko (custodial)

Avaa Wallet. Näet:

  • Osoitteesi (0x…) — tämä on se lompakko, jolla miner / stake / swap toimivat
  • HEL- ja tBNB-saldot ketjussa
  • Siirrot toiselle Helion-käyttäjälle (ilmainen) tai ulkoiseen 0x-osoitteeseen (fee)
Kopioi Wallet-sivulta oma Helion-osoitteesi. Siihen siirrät faucetista saadun tBNB:n. Ilman tBNB:tä lompakossa näet virheen “tBNB-varat vähissä” kun aktivoit kaivoksen tai teet muita ketjutapahtumia.

3. Hae tBNB ja siirrä Helion-lompakkoon

Gas maksetaan testnet-BNB:llä (tBNB). Sitä ei osteta pörssistä — se haetaan faucetista.

Vaihe A — Hae tBNB faucetista

  1. Asenna MetaMask ja lisää BSC Testnet (ohje alla §5).
  2. Kopioi MetaMask-osoitteesi (tai suoraan Helion-osoite, jos faucet hyväksyy sen).
  3. Avaa faucet, liitä osoite ja pyydä tBNB:tä (usein 0.05–0.3 tBNB / 24h).

BNB Chain virallinen faucet QuickNode faucet (vaihtoehto) BscScan Testnet

Jotkut faucetit vaativat pienen saldon BSC mainnetissä bottien torjuntaan. Jos faucet estää, kokeile toista linkkiä tai odota cooldown.

Vaihe B — Siirrä tBNB Helion-custodial-lompakkoon

  1. Avaa Wallet → kopioi Helion-osoitteesi (0x…).
  2. MetaMaskissa: verkko = BSC Testnet.
  3. Send → liitä Helion-osoite → määrä esim. 0.05 tBNB → Confirm.
  4. Odota vahvistus (testnet.bscscan.com). Päivitä Wallet-sivu — tBNB-saldon pitäisi näkyä.
Tärkeää: Jos tBNB jää vain MetaMaskiin eikä Helion-osoitteeseen, miner/stake/swap eivät toimi, koska tapahtumat allekirjoitetaan custodial-avaimella.

4. Ominaisuudet — mitä tehdä missä

⛏ Miner

  1. Varmista että Helion-lompakossa on tBNB:tä (gas).
  2. Miner → Aktivoi kaivos (12h).
  3. Odota syklin loppuun → Claim palkkio HEL:inä lompakkoon.

🔒 Staking

  1. Tarvitset HEL-saldoa (esim. minerista tai swapista) + tBNB gasiksi.
  2. Staking → valitse taso (lukitusaika) → stake.
  3. Lukituksen jälkeen nosta; aikainen nosto menettää tuoton.

🔄 Swap / likviditeetti

  1. Swap: HEL ↔ tBNB (testnet).
  2. Gas maksetaan tBNB:llä custodial-lompakosta.
  3. Voit myös lisätä/poistaa likviditeettiä pooliin.

📈 Spot (HEL/BNB)

  1. Spot on sisäinen order book (ei erillistä MetaMask-signia joka tradeen).
  2. Talleta HEL/BNB spot-tilille (deposit) Wallet/ketjusaldoista → aseta limit/market → nosta (withdraw) tarvittaessa.
  3. Deposit/withdraw voivat vaatia ketjutapahtuman ja siis tBNB:tä.

💼 Wallet & 🏆 Board

  • Wallet: saldot, osoite, siirrot, MetaMask-linkitys.
  • Leaderboard: pisteitä stakeista, kaupoista, louhinnasta ja lähetyksistä.

6. Usein kysyttyä

”tBNB-varat vähissä” / insufficient funds

Custodial-lompakossa on 0 (tai liian vähän) tBNB:tä. Hae faucetista ja siirrä Helion-osoitteeseen (§3).

Rekisteröidyin mutta en näe tBNB:tä

Uusi lompakko on tyhjä. Faucet → siirto Helion-osoitteeseen.

Miner ei aktivoidu vaikka MetaMaskissa on tBNB

MetaMask ≠ Helion-custodial. Varat pitää olla Helion-osoitteessa (Wallet-sivu).

Data katoaa restartissa

Tuotannossa tarvitaan Upstash Redis (persist=upstash). Paikallisesti data voi olla tiedostoissa.

1. Create account & sign in

  1. Open the login page.
  2. Choose Register, enter username and password.
  3. Helion automatically creates a BSC custodial wallet for you.
  4. After login you can use Wallet, Miner, Staking, Swap and Spot.

You can later link a MetaMask address on the Wallet page (optional).

2. Helion wallet (custodial)

Open Wallet. You will see:

  • Your address (0x…) — used for miner / stake / swap
  • HEL and tBNB on-chain balances
  • Transfers to another Helion user (free) or external 0x (fee)
Copy your Helion address from Wallet. Send faucet tBNB there. Without tBNB in this wallet you will see “Low tBNB” when activating mining or other chain txs.

3. Get tBNB and send it to Helion

Gas is paid in testnet BNB (tBNB) from a faucet — not from a CEX.

Step A — Faucet

  1. Install MetaMask and add BSC Testnet (§5).
  2. Copy your MetaMask address (or Helion address if the faucet allows it).
  3. Open a faucet, paste the address, request tBNB (often 0.05–0.3 / 24h).

BNB Chain official faucet QuickNode faucet (alternative)

Some faucets require a small BSC mainnet balance for anti-bot checks.

Step B — Send tBNB to Helion custodial wallet

  1. Open Wallet → copy your Helion address.
  2. In MetaMask set network to BSC Testnet.
  3. Send → paste Helion address → amount e.g. 0.05 tBNB → Confirm.
  4. Wait for confirmation, refresh Wallet — tBNB should appear.
Important: tBNB only in MetaMask is not enough. Miner/stake/swap use the Helion custodial key.

4. Features

⛏ Miner

  1. Ensure Helion wallet has tBNB for gas.
  2. Miner → Activate mining (12h).
  3. When the cycle ends → Claim HEL rewards.

🔒 Staking

  1. Need HEL + tBNB for gas.
  2. Staking → pick tier → stake.
  3. Withdraw after lock; early exit forfeits yield.

🔄 Swap / liquidity

  1. Swap: HEL ↔ tBNB on testnet.
  2. Gas paid in tBNB from custodial wallet.

📈 Spot (HEL/BNB)

  1. Spot internal order book.
  2. Deposit HEL/BNB → place orders → withdraw when needed.
  3. Deposit/withdraw may require on-chain txs and tBNB.

6. FAQ

“Low tBNB” / insufficient funds

Custodial wallet has too little tBNB. Use a faucet and send to Helion address (§3).

I registered but see no tBNB

New wallets are empty. Faucet → transfer to Helion.

Miner fails even though MetaMask has tBNB

MetaMask ≠ Helion custodial. Funds must be on the Helion address (Wallet page).
